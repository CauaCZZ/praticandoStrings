# Praticando Strings e Regex

Exercícios desenvolvidos durante meus estudos de Java no curso da Alura, com foco em manipulação de Strings e Expressões Regulares (Regex).

## 📚 Conteúdos praticados

Durante os exercícios, pratiquei:

- Manipulação de Strings
- Busca e substituição de palavras
- Conversão de texto para maiúsculas e minúsculas
- Remoção de espaços desnecessários
- Formatação de valores
- Validação de dados com Regex
- Uso de Expressões Regulares para identificar padrões em textos
